# App fonts

Figtree weights 400, 500, 600, 700 and 800 are served locally by `src/styles/fonts.css`, matching the `frontend` branch typography tokens. Source: Google Fonts Figtree, https://fonts.google.com/specimen/Figtree. The SIL Open Font License is included in `figtree-LICENSE.txt`.

Previously bundled Switzer files are retained as existing assets but are not loaded by the application.
